# Glossar

| Begriff | Bedeutung |
|---|---|
| **Lauf** | Roguelike-Durchgang durch mehrere Level → [[Roguelike-Läufe]] |
| **Tiefe** | Nummer des Levels im Lauf, steuert Gegnerzahl und Belohnung |
| **Option** | eines der 2–3 wählbaren Level vor jedem Kampf (Kampf oder Lager) |
| **Lager / Rast** | Halt ohne Kampf: Heilung, Teamwechsel, Wiederbelebung → [[Bosse und Lager]] |
| **Miniboss / Boss** | feste Gegner in Level 3 und 5 eines Gebiets |
| **Gegnerschwerpunkt / Thema** | Axt-, Lanzen- oder Bogentrupp |
| **Kartenstück (Chunk)** | handgemachter 8 × 4-Baustein für den [[Levelgenerator]] |
| **Pity** | garantierte Seltenheit nach X Rufen → [[Rekrutierung]] |
| **Verschmelzen** | Duplikat eines Helden macht ihn stärker |
| **Waffendreieck** | Schwert > Axt > Lanze > Schwert → [[Kampfsystem]] |
| **Rückblende** | Zug zurücknehmen (`Undo`) |
| **Thronlande** | schwebende Insel über dem Wolkenmeer, auf der die Kampflevel liegen → [[Thronlande]] |
| **Hub / Thronsaal** | Lobby mit Einrichtungen → [[Thronsaal-Hub]] |
| **Chibi** | eigene Teile-Figuren als Platzhalter |
| **Handoff** | Übergabe Claude ↔ Codex über `PLAN.md` und `.handoff/status` → [[Arbeitsablauf]] |
